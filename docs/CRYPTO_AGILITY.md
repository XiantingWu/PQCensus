# Crypto agility

`pqcensus agility PATH` reports a deterministic 0-100 engineering score with component scores and evidence. The range is a declared engineering scale: it is not a normalized population percentile and not an externally calibrated maturity score. Components cover algorithm selection, provider centralization, negotiation, dual/hybrid support, key rotation, certificate rotation, dependency constraints, and policy centralization.

Signals come from verified findings, structured configuration, dependency metadata, paths, and explicitly named lexical hints. The output states that absence of a static signal is not proof that a capability is absent. This is not an AI score, certification, maturity model, or substitute for architecture review.

The dimensions align with the replacement/adaptation concerns described by NIST CSWP 39 update 1. PQCensus's weights and thresholds are its own documented engineering interpretation, not NIST scoring guidance.
